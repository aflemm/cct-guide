# Multiple Windows on iPad

The SmartBroom iPad app supports multiple windows. Each window can work with its own broom, so a coach can watch two athletes' live sessions on the same iPad.

## Set up one broom per window

1. Open SmartBroom and connect the first broom from that window's **Discovered** list.
2. Open another SmartBroom window using iPadOS. For example, touch and hold the SmartBroom app icon and choose **New Window**, then arrange the windows alongside each other.
3. In the new window, open **SmartBroom** and connect the second broom from **Discovered**.
4. Check the device name and serial number in each window, then open **Start New Session** for each broom.
5. Select the appropriate sweeper and use **Start New Sweep** in each window when ready.

Each broom has its own live session and start/stop controls. You can watch one athlete while preparing the next sweep for the other. A sweep started or stopped in one broom's window does not start or stop the other broom's sweep.

For the current iPadOS window controls, see Apple's [guide to opening multiple windows of an app](https://support.apple.com/guide/ipad/ipad8dfdf86b/ipados).

## What is shared?

The windows share the app's connected-device list, saved records, sweepers, settings, and bonding keys. They are separate views of the same app, not separate accounts or data stores.

A broom already assigned to another window is labelled **Open in another window**. Use that window to control it. To move it, finish the current live sweep and close its window; it can then be opened from **Connected** in the other window.

Disconnecting a broom ends that broom's shared Bluetooth connection. Closing a window is not a substitute for stopping and saving a live sweep first.

## A practical coaching setup

The sweeps remain associated with their respective brooms and sweepers in **Review**, so you can compare the athletes after practice.

For recording without keeping the iPad connected, prepare each broom individually for [Background Recording](background-recording.md). Claiming each broom once is sufficient; see [Bonding and Ownership](bonding.md).
